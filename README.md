# Hearthside beta

A quiet place, together. Study at home, invite someone over, or join a shared exam hall.

[Website and installation instructions](https://hearthside-beta-livid.vercel.app) · [Download the free Mac or Windows beta](https://github.com/flxnaf/hearthside-beta/releases/tag/v0.15.4)

No GitHub account is needed to download. This repository contains exported releases, player instructions and package tests. The game development project is not published.

Mac requires macOS 13 or newer; tested on Apple Silicon. Windows 10/11 x64 is an early build. Keep the extracted Windows folder together. Verse and optional camera checks are Mac-only. Windows package startup, movement, hosting and internet invitations have passed automated checks on a Windows runner; desktop GPU/audio testing is still pending.

The Mac app is not notarized and the Windows executable is unsigned. Follow the instructions included with the download. Do not disable security settings or bypass malware warnings. SHA-256 checksums are attached to each release.

The public halls have connection limits, bounded drawing traffic and operator controls. This is still a beta: interruptions can happen, guest names are not verified identities, and the halls are not watched continuously. Friends accounts are not implemented yet. See the [privacy page](https://hearthside-beta-livid.vercel.app/privacy.html).

[Report a bug](https://github.com/flxnaf/hearthside-beta/issues). Reports are public; leave out private invitation links and personal information.
