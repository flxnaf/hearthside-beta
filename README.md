# Hearthside Mac beta

A quiet place, together.

This repository contains beta downloads and installation instructions only. The game development repository is private.

The current beta is free, for macOS 13 or newer. Tested on Apple Silicon; Intel is not yet validated. The app is ad-hoc signed and not notarized. Read START-HERE.txt in the download before opening.

Currently a private review release. Public access is pending launch readiness.
